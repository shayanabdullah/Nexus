### 2. Multi-Agent AI Cognition Engine

### 3. Fortified Authentication Core
* **Real Firebase Integration:** Implements active Firebase Auth and Firestore profile synchronization.
* **Google OAuth Handshake:** Allows secure authentications using pop-up callbacks.

## ⏱️ Quick Start & Local Execution

Follow these steps to run the application locally on your machine.

### 1. Prerequisites
Ensure you have **Node.js v18+** and **npm** installed on your secure terminal environment.

### 2. Install Project Dependencies
```bash
npm install
```

### 3. Setup Firebase Config
Generate your standard Firebase app config, save it as `firebase-applet-config.json` at the root, or insert appropriate environment flags in your `.env.example` file.

### 4. Direct Development Server Boot
To launch the interactive dev portal dynamically:
```bash
npm run dev
```

### 5. Production Build & Bundling
To compile assets and package CJS Node middleware for lightning-fast container deployment:
```bash
npm run build
```
